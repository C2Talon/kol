## Utility {#Utility}

### [update-kolmafia](https://github.com/C2Talon/update-kolmafia)

Perl script to check for the latest KoLmafia release and to download it
if needed, then create a symlink to it. Binary executables available to
download for those without Perl installed

### [vim-kolmafia](https://github.com/C2Talon/vim-kolmafia)

Vim syntax highlighting for the ASH scipting language KoLmafia uses

## Scripts {#Scripts}

### [c2t_megg](https://github.com/C2Talon/c2t_megg)

Adds various interfaces for mimic eggs from the chest mimic, to include
CLI commands, ASH functions, and relay override scripts for the choice
adventures

### [c2t_ascend](https://github.com/C2Talon/c2t_ascend)

Automates Valhalla, to include entering Valhalla, buying astral items,
perming skills, and leaving valhalla

### [c2t_apron](https://github.com/C2Talon/c2t_apron)

Handles usage of the Black and White Apron Meal Kit

### [c2t_hccs](https://github.com/C2Talon/c2t_hccs)

Fully automates a Community Service run with the things that are
available to me

### [c2t_kol_scripts](https://github.com/C2Talon/c2t_kol_scripts)

A variety of small, single-purose, stand-alone scripts

### [c2t_trainer](https://github.com/C2Talon/c2t_trainer)

Automatically train people with the crimbo training manual if they send
you a kmail request to do so
:::

## Relay Override Scripts {#Relay Override Scripts}

### [c2t_megg_relayCombat](https://github.com/C2Talon/c2t_megg_relayCombat)

Relay override script for `fight.php` that adds a line of text to denote
whether a monster in combat already has its mimic eggs maxed or not

### [c2t_takerSpace_relay](https://github.com/C2Talon/c2t_takerSpace_relay)

Adds a few quality of life features to the TakerSpace choice adventure

### [fake_hand_relay](https://github.com/C2Talon/fake_hand_relay)

Compresses the display of equipped fake hands on profiles and in the
player\'s inventory
:::

::: article
## Choice Adventure Scripts {#Choice Adventure Scripts}

### [c2t_choices_ook](https://github.com/C2Talon/c2t_choices_ook)

Automate and track the \"Ook the Mook\" choice adventure chain in the
Time-Twitching Tower
:::

::: article
## Libraries {#Libraries}

### [liba](https://github.com/C2Talon/liba)

Library of ASH functions for use in scripts in Kolmafia. Mainly
functions for IotMs and other things that may not have their own native
KoLmafia functions

### [c2t_lib](https://github.com/C2Talon/c2t_lib)

Collection of functions I use in various scripts
:::

### [c2t_trainRando](https://github.com/C2Talon/c2t_trainRando)

Randomly give another player the skill from the crimbo training manual
item. Only worked during Crimbo 2022
